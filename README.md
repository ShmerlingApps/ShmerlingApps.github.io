# Shmerling Apps website

Static site for Shmerling Apps and Downabit: app page, privacy policy, terms, support, data deletion and
subscription pages - the addresses Google Play and the Amazon Appstore ask for.

## Edit

All pages are generated by `build.mjs` (Node 18 or newer). Change the text, the contact email or a store link
there, then run:

    node build.mjs

and commit the regenerated HTML. GitHub Pages serves the files as they are; nothing is built on GitHub.

## Addresses to paste into the stores

With the custom domain shmerling.app (the app already links to shmerling.app/downabit/subscribe):

| Store field | Address |
|---|---|
| Privacy policy | https://shmerling.app/downabit/privacy/ |
| Website / marketing URL | https://shmerling.app/downabit/ |
| Support (Amazon) | https://shmerling.app/downabit/support/ |
| Account and data deletion (Google Play data safety) | https://shmerling.app/downabit/delete-data/ |

Without a custom domain, replace `https://shmerling.app/` with `https://<github-user>.github.io/<repository>/`.

## Publish with GitHub Pages

1. Push this folder to a GitHub repository. On a free GitHub plan the repository must be public for Pages.
2. Repository > Settings > Pages > Build and deployment: Source "Deploy from a branch", branch `main`, folder `/ (root)`.
3. Custom domain (optional): enter `shmerling.app`, then at your domain registrar add the DNS records GitHub shows
   (four A records for the apex domain, or a CNAME for a subdomain), and tick "Enforce HTTPS" once it is offered.
